EL ARISH BOOKS — Modern website

1) افتح index.html في المتصفح لمعاينة الموقع.
2) لتغيير اسم مدرس أو مادة، افتح index.html بمحرر نصوص وابحث عن arrays:
   - subjects: المواد
   - teachers: أسماء المدرسين والتخصصات
3) نموذج الطلب يفتح واتساب برسالة جاهزة، لكنه لا يرسل تلقائياً.
4) لتوجيه الطلب لرقم المشروع، غيّر رابط wa.me في نهاية ملف index.html إلى:
   https://wa.me/201XXXXXXXXX?text=
   واكتب رقم المشروع بصيغة دولية بدون + أو مسافات.
5) صور المدرسين الحقيقية غير مضافة حتى لا ننسب صورة لشخص بالخطأ. البطاقات الحالية تستخدم أحرفاً أولى مؤقتة.
6) الموقع نسخة ثابتة قابلة للتعديل، ولم يتم نشره على الإنترنت بعد.


التحديث الأخير:
- إضافة رابط مستقل للمدرسين.
- إضافة قسم للكتب والمراجع.
- إضافة قسم للباكدجات والعروض، مع خانات مؤقتة للصفوف والأسعار والمحتويات التي ستُضاف لاحقاً.
- أسماء المدرسين والكتب والأسعار الحالية ليست قائمة بيع نهائية؛ حدّثها بعد التأكد من التوافر.
